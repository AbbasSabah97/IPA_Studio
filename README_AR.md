# IPA Studio Trusted Edition 4.0 — التوقيع المجاني على Windows

**هذا مشروع مصدر جاهز للبناء وليس مُثبِّت Windows مبنياً أو تطبيقاً تم اختباره على آيفون حقيقي.**

يقدم واجهة Python تستخدم محرك [iPASide](https://github.com/pwnapplehat/iPASide) المفتوح المصدر، المحدد على commit:
`be811fcaea8556fe5108dd25279d626fa0d56435`، مع نسخة zsign من commit:
`9299685bab7ef99827e06e5dfda93af747386590` وإصلاح أمني لتمرير كلمة مرور P12 عبر stdin.

## الوظائف

- حساب Apple ID عادي، دون اشتراك مطور مدفوع؛ قد يتطلب التحقق الثنائي 2FA.
- خدمة Anisette V3 واحدة يختارها المستخدم صراحةً، دون خادم احتياطي مخفي.
- الإصدار المجاني للشهادة وملف التهيئة يُطلب من **Apple** بواسطة محرك iPASide، وليس من خادم Anisette.
- فحص IPA محلياً، توقيعه ونسخه إلى الآيفون عبر **USB فقط** (لا Wi-Fi fallback).
- إعادة توقيع التطبيقات المدونة يدوياً قبل انتهاء صلاحية التوقيع (غالباً 7 أيام).
- نسخة اختيارية من IPA الموقع.
- لا حاجة لتنزيل iPASide منفصلاً على حاسوب المستخدم بعد بناء المثبت بنجاح.

## ما الخوادم المستخدمة؟

أحد **خادمين مجتمعيين** لتوفير Anisette فقط، بعد اختيارك وموافقتك:

1. **SideStore V3:** `https://new.ani.sidestore.io` (الافتراضي المقترح).
2. **jkcoxson Mac V3:** `https://mac-ani.jkcoxson.com`.

لا ينتقل البرنامج تلقائياً إلى الثاني إذا فشل الأول؛ تغيير المزود يتطلب موافقة جديدة.
وتجري المصادقة وإصدار بيانات التوقيع مباشرةً مع **خوادم Apple** (`gsa.apple.com` و`developerservices2.apple.com`) في التصميم المثبت لهذا الإصدار. إذا تطلبت Apple خادماً إضافياً نتيجة تغيّر خدماتها، ترفض سياسة الشبكة اتصال المحرك إلى حين مراجعة الشيفرة وتحديث القائمة.

**مهم حول الخصوصية:** المشغّل الخارجي لخادم Anisette قد يرى IP ومعرّف تهيئة عشوائياً ورسائل بروتوكول معتمة. وفق تصميم iPASide V3، لا يُرسل إليه بريد Apple ID أو كلمة المرور أو OTP أو التوكن. لا يمكننا إثبات أمان الخوادم العامة أو ضمان تشغيلها دائماً؛ استخدم حساب Apple منفصلاً عن حساب iCloud الأساسي إذا أردت الحد من المخاطر.

محرك iPASide يحفظ جلسات المصادقة والشهادات على حاسوبك في `%LOCALAPPDATA%\iPASide`، **ورموز الجلسات المحفوظة في ملفات JSON ليست مشفرة بواسطة DPAPI في المصدر المثبّت**. هذا قيد أمني معروف؛ لا تستخدم هذا الإصدار على حاسوب مشترك أو غير موثوق. كلمة مرور Apple لا تُحفظ بواسطة واجهة IPA Studio ولا ينبغي وضعها في GitHub.

يستخدم المشروع حاجز اتصالات *داخل Python* (`policy/sitecustomize.py`) يمنع DNS والاتصالات الخارجية عدا العناوين المذكورة، إضافةً إلى loopback المحلي المستخدم لUSB. **الحاجز ليس بديلاً عن Windows Firewall أو ضماناً ضد برمجيات خبيثة أو مكتبات أصلية تتجاوز Python socket.** Apple Devices قد يجري اتصالات مستقلة من خلال خدمات Windows التي لا يتحكم بها التطبيق.

## بناء ملف Setup.exe على GitHub

1. أنشئ مستودع GitHub خاصاً، ثم ارفع **محتويات** ZIP بما في ذلك مجلد `.github`.
2. افتح `Actions` ثم `Build IPA Studio Trusted v4 (Windows)`.
3. اضغط `Run workflow` وانتظر نجاح عملية البناء.
4. نزّل Artifact المسمّى `IPAStudio-Trusted-v4-Windows-Setup`.
5. افحص SHA-256 باستخدام ملف `SHA256SUMS.txt`، ثم شغّل `IPAStudio-Trusted-Setup-4.0.0.exe`.

إن فشلت أي مرحلة، **لا تنزّل أو تستخدم نتيجة بناء غير مكتملة**. يستخدم البناء الإنترنت لتنزيل مكتبات البناء من GitHub وPyPI وMSYS2؛ هذا منفصل عن اتصالات البرنامج عند تشغيله. لا ترفع كلمات المرور أو ملفات IPA أو شهادات P12 إلى مستودع GitHub.

### خطوات الاستخدام بعد التثبيت

1. ثبّت **Apple Devices** من Microsoft Store أو تعريفات Apple الرسمية، وصِل الآيفون بUSB، وافتح قفله واختر **Trust**.
2. افتح البرنامج ثم `الخصوصية والإعدادات`. اختر **SideStore V3** أو **jkcoxson Mac V3** واقرأ معلوماته، ثم فعّل مربع الموافقة.
3. انتقل إلى `Apple ID`، أدخل حساب Apple العادي وكلمة مروره، ثم أكمل 2FA إذا طلبته Apple. اضغط `حالة الحساب` للتحقق.
4. من `الرئيسية · IPA` اضغط **تحديث الأجهزة**، وحدد آيفونك المتصل بUSB.
5. اختر `MyApp.ipa` واضغط **فحص ملف IPA**.
6. اضغط **وقّع وثبّت على الآيفون**. يطلب المحرك شهادة/بروفايل من Apple ويوقع IPA محلياً ويرسله عبر USB إلى الهاتف.
7. على الآيفون قد تحتاج إلى `Settings > Privacy & Security > Developer Mode` وإلى الثقة بالمطور في `Settings > General > VPN & Device Management`.
8. بعد 5–6 أيام، وصل الهاتف وافتح `عرض التطبيقات > تجديد المحدد` أو `جدّد كل التطبيقات`.

**هذا التدفق لم يخضع بعد لاختبار حقيقي على Windows + iOS 26**؛ آلية Apple قد تتغير. بعض IPAs المشفرة بـFairPlay، أو التي تتطلب entitlements غير متاحة في الحساب المجاني، قد لا تعمل حتى لو اكتمل التوقيع. حدود Apple للحساب المجاني تشمل التجديد بعد 7 أيام وعدداً محدوداً من التطبيقات المسجّلة.

## أمن كلمة المرور

- حساب Apple وكلمة المرور ينتقلان إلى **محرك iPASide المضمن** في متغيرات بيئة العملية؛ يتم اتصال تسجيل الدخول مباشرة مع Apple وفق الشيفرة المدققة، وليس عبر Anisette.
- رمز 2FA ينتقل عبر متغير بيئة `IPASTUDIO_2FA_CODE` (مع تعديل محلي في المحرك) بدلاً من وسائط العملية.
- رمز سر ملف P12 الذي يولده المحرك يمر إلى `zsign.exe` عبر stdin بعد تعديل المصدر، وليس كوسيط `-p secret` مكشوف.
- رموز جلسة Apple والمفاتيح الخاصة تبقى محفوظة محلياً، لكن حماية مخزن جلسة upstream ما زالت تحتاج مراجعة وتحسيناً قبل استخدامها على أجهزة متعددة المستخدمين.
- لا ترفع ملف تثبيت مبنياً من مستودع غير موثوق، ولا تتجاهل تحذير SmartScreen دون التحقق من المصدر والبصمة.

## الاختبارات

`python -m unittest discover -s tests -v`

تتحقق الاختبارات من إعدادات الشبكة، ورفض خادم غير مسموح، وعدم ظهور 2FA وكلمة المرور في command args، وحظر DNS الخارجي، وفحص IPA. **هي ليست اختبار اختراق، ولا اختبار توقيع Apple فعلياً.**
